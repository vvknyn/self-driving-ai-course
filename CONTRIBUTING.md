# Contributing

## Report an error

Open an issue at https://github.com/vvknyn/self-driving-ai-course/issues with:

- the unit (for example `0.1.2-images-are-arrays`) and the file or lab cell;
- what you expected and what you saw: quote the sentence, paste the traceback or the grader output;
- your Python version and whether you ran locally, in Colab or in the browser playground.

A wrong number, a figure that does not match its text and a lab that grades wrongly all count as errors.

## Send a fix

1. Fork the repository and branch from `main`.
2. Set up: `python3 -m venv .venv && source .venv/bin/activate && pip install -e ".[dev]"`.
3. Edit the source files. `lab.ipynb` is generated from `lab.py`: edit `lab.py`, then run `python scripts/build_labs.py`. Figures are generated by the unit's `figures.py`.
4. Run the gates below and say in the pull request which you ran.

## The gates

```bash
python scripts/build_labs.py --check     # every lab.ipynb matches its lab.py
python scripts/verify_units.py           # starter fails the grader, reference solution passes
python -m pytest                         # whole suite; or one file: python -m pytest tests/zero2fsd/test_car.py
```
