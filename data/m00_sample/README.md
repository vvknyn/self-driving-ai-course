# Module 00 sample crops

Synthetic 64×64 RGB driving-scene crops for the Week 1 classifier lab. These are **not** photographs; they are procedurally drawn asphalt / vehicle / pedestrian / lane patches generated by `generate_crops.py` with **seed 42**.

## Regenerate

```bash
python data/m00_sample/generate_crops.py
```

## Layout

- `labels.csv` — columns: `filename`, `split`, `label`, `class_name`
- `*.png` — checked-in training images (training code loads files; no `torch.randn` fallback)
